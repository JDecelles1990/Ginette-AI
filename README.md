# Ginette-AI

> Historical Python learning project

Ginette-AI is an early Python voice-assistant experiment created while I was learning Python and exploring speech-driven software.

The project focused on a simple concept: use a vocal assistant to perform Wikipedia searches and return information to the user.

## Project history

- Original learning period: 2021
- Uploaded to GitHub: November 8, 2022
- Current status: Historical learning project
- Purpose today: Preserve an early example of my programming progress

This repository is intentionally preserved close to its original form. It does not represent my current engineering standards, architecture practices, testing approach, or development workflow.

## Why this repository remains public

I keep Ginette-AI as part of my development history.

It shows that I was experimenting with Python and assistant-style software before my current AI-assisted software-engineering workflow. Rather than rewriting the original source to make it look modern, I prefer to preserve it as evidence of how my skills evolved.
